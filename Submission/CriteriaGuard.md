## Project Details

**Project Title:**  
CriteriaGuard: Governance-Grade AI for Procurement

**Project Description:**  
CriteriaGuard is a high-integrity, end-to-end explainable AI platform designed to automate the manual, error-prone process of cross-checking bidder submissions against tender eligibility criteria. Built specifically for the complexities of Indian Government Procurement, it ensures every decision is deterministic, traceable, and fully auditable. The platform leverages Llama 3.3 70B (Groq) for structured criteria extraction (CriteriaLens), runs evaluations via a deterministic Python rules engine (VerdictCore) to eliminate hallucinations, logs evaluations with SHA-256 chained tamper-evident logs, and integrates an Officer Checkpoint and Review Queue for human-in-the-loop governance.

**Tech Stack Used:**  
FastAPI, React (Vite), Groq / Llama 3.3, Google Cloud Vision OCR / Tesseract, PostgreSQL (Supabase), ReportLab
