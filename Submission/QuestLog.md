### 📝 Project Description
QuestLog is an immersive, text-based dark-fantasy RPG showcase where players interact with an AI Dungeon Master (DM) that has persistent "eternal memory". 
LLM-driven games usually suffer from context memory loss where the DM forgets the adventurer's items, quest journal status, and met NPCs after several turns. QuestLog integrates the **Memori SDK** to solve this: every major accomplishment, item acquired, damage taken, and quest log event is automatically captured as persistent background facts and dynamically recalled back into the DM's context, ensuring narrative consistency.
The project features a gorgeous real-time glassmorphic dark-fantasy dashboard showcasing player stats, inventory slots, live quest logs, and a dedicated Developer's Memory Console showing the SDK memory debugger in real time.
