## Project Details

**Project Title:**  
OpenForge — Your First Open-Source PR in Minutes

**Project Description:**  
OpenForge is a platform designed to help beginner developers make their first open-source contribution faster by removing the biggest barrier: discovery.

It indexes curated GitHub repositories and surfaces real-time "good first issue" tasks in a clean, searchable interface. Instead of spending hours searching across GitHub, users can instantly explore beginner-friendly issues, filter projects by technology, difficulty, and tags, and access live GitHub data with caching for performance.

The goal is simple: reduce the time to first open-source contribution from hours to minutes.

**Tech Stack Used:**  
Python (Flask), GitHub REST API, JavaScript, HTML, CSS, Netlify, Render
