## Project Details

**Project Title:**  
Sortify AI

**Project Description:**  
Sortify AI is an AI-powered email command center that transforms a cluttered Gmail inbox into an organized, actionable dashboard. It uses the Google Gemini API to automatically triage, categorize, and prioritize incoming emails, draft smart replies, detect phishing threats, and manage newsletter subscriptions — all from a single sleek dark-themed interface. It features a zero-auth Sandbox Demo Mode so anyone can explore instantly, along with real Gmail integration via OAuth for live inbox management. Key capabilities include Smart Snooze, Thread Summarization, an Inbox Intelligence Center with volume charts and heatmaps, a Rule Learning Engine, and a Security/Phishing Shield.

**Tech Stack Used:**  
Python, Flask, Google Gemini API, Gmail API, SQLite, HTML/CSS/JavaScript, GSAP (animations), Progressive Web App (PWA), Docker, Gunicorn
