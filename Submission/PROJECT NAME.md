Project Details

Project Title:
OrderTrack – Smart Order Management System

---

Project Description:

OrderTrack is a web-based Order Management System designed specifically for wholesalers and order-based businesses that handle bulk and custom orders.

Traditional notebook-based systems create issues like calculation errors, poor order tracking, and difficulty managing pending payments. OrderTrack solves this by digitizing the entire workflow.

With OrderTrack, users can:

- Create and manage multi-item orders
- Automatically calculate total, advance, and remaining payments
- Track order status and payment status
- Maintain a complete order history
- Communicate with customers using call and WhatsApp features

The project focuses on real-world business problems and provides a simple, efficient, and scalable solution.
