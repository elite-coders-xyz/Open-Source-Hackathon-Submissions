## Project Details

**Project Title:**  
Clutch — Developer Activity Dashboard

**Project Description:**  
Clutch is an open source developer activity dashboard that fills the gaps GitHub doesn't — giving developers a mindful view of how they actually work, not just what they ship.
It connects to your GitHub via OAuth and uses the GitHub GraphQL API to pull real commit data, then surfaces it as streak tracking, activity charts, coding pattern detection, and AI-powered weekly summaries generated by Groq. Every insight is personal — your best day, your consistency score, your most active repositories.
Beyond the web dashboard, Clutch ships a fully functional CLI built with Typer, so developers can run clutch streak or clutch insight directly from the terminal without opening a browser. The CLI connects to the same FastAPI backend, making it a true multi-interface tool.
The project is designed for the long term — with a clear 45-day open source roadmap, good first issues for contributors, and integration hooks planned for WakaTime, GitLab, Dev.to, and PyPI publishing. Every part of the stack is documented, structured for contributors, and deployed live.
<br><br>
GitHub tracks your work. Clutch tracks you.
<br><br>
The current state of the project is an MVP and there is still a lot of polishing left to do, but the core idea has genuine potential to scale into something much larger — a tool that every developer actually wants open on their second monitor. Thank you for the opportunity.

**Tech Stack Used:**  
Tech Stack: Python, FastAPI, SQLAlchemy, React, TypeScript, Tailwind CSS, Groq API, GitHub GraphQL API, Typer, Render, Netlify
