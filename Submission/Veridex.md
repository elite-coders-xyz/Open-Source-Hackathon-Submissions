## Project Details
- **Project Title:** Veridex
- **Project Description:** Veridex is a public information reliability platform where users submit claims, attach supporting sources (including PDFs that are parsed automatically), and the community evaluates and discusses how trustworthy each claim is. It pairs transparent, rule-based reliability scoring with an optional AI evidence check (Google Gemini) that judges whether each source supports, contradicts, or is unrelated to a claim, and it tracks each claim's reliability history over time.
- **Tech Stack Used:** Node.js, Express.js, MongoDB (Mongoose), JWT, bcrypt, Multer, Nodemailer, HTML, CSS, JavaScript, Bootstrap, Google Gemini API
