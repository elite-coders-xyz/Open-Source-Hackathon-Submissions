## Project Details

**Project Title:**  
Placement Prep Assistant

**Project Description:**  
Placement Prep Assistant is an AI-powered interview prep chatbot for students targeting technical placements. Ask any question on DSA, DBMS, OS, OOP, or Machine Learning and get a structured, interview-ready answer — with definitions, examples, interview tips, curated articles, and YouTube recommendations, all in one place.

Built with a RAG pipeline (FAISS + LangChain + Groq's LLaMA 3.3-70B), it retrieves answers from a hand-curated 24-topic knowledge base and enriches them with real-time web search via Tavily. A hybrid routing engine seamlessly blends knowledge base retrieval with general LLM reasoning based on query relevance.

The problem it solves: Most prep tools give generic answers. This assistant responds like a senior engineer coaching you for your interview — not a search engine returning blue links.
**Tech Stack Used:**  
Python · Streamlit · LangChain · Groq LLaMA 3.3-70B · HuggingFace Embeddings · FAISS · Tavily API · YouTube Data API v3 · python-dotenv · Streamlit Cloud
