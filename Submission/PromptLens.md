## Project Details

**Project Title:**  
PromptLens

**Project Description:**  
PromptLens is an open-source, self-hostable AI prompt engineering workbench that helps developers, AI engineers, and prompt engineers write, test, debug, and optimize their prompts — the same way they use unit tests and linters for code. It features a side-by-side prompt diff tool, prompt autopsy and security linter, a mutation engine to generate variants, and a multi-dimensional scoring dashboard.

**Tech Stack Used:**  
React 19, Vite, Tailwind CSS v4, FastAPI (Python), SQLite, SQLAlchemy, Groq API (LLaMA 3.1)
