## Project Details

**Project Title:**
StockSense

**Project Description:**
StockSense is a stock analytics platform that enables users to search publicly traded companies and view key technical indicators. Users can search by company name or ticker symbol and access metrics such as moving averages, volatility, and trading volume. The project combines a Node.js backend with Python-powered financial analysis using Yahoo Finance data and includes a responsive web interface with search and analytics views.
