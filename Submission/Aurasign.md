## Project Title
AuraSign – Real-Time Sign Language Translator

## Project Description
AuraSign is an AI-powered web application that translates sign language gestures into real-time text and speech using MediaPipe Hands and TensorFlow.js.

## Tech Stack
- React
- TypeScript
- TensorFlow.js
- MediaPipe Hands
- Vite
- CSS
