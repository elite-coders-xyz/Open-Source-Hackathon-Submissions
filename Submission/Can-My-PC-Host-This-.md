## Project Details

**Project Title:**  
Can My PC Host This?

**Project Description:**  
**Can My PC Host This?** is a local tool for Docker Compose stacks only. It checks your actual PC hardware, rewrites your compose file with safe resource limits, and helps prevent freezes or crashes when self-hosting home servers, dev stacks, or media apps.

**What makes it different:**

- **Purpose-Built:** Designed specifically for Docker Compose stacks, not a generic cloud service.
- **100% Local:** Runs completely locally with no external AI or cloud dependencies.
- **Hardware-Aware:** Uses actual host CPU/RAM data and lets you override it manually for simulation.
- **Automated Safety:** Adds safe `deploy.resources.limits` automatically to your files.
- **Preset Profiles:** Includes native modes for quiet background use, balanced dev work, or higher performance.
