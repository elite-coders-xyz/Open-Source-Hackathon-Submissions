## Project Details

**Project Title:**
NagarAI

**Project Description:**
The idea behind NagarAI is to address the persistent problem of fragmented urban services in cities like Delhi/NCR, where citizens face scattered information, slow issue resolution, lack of real-time updates, and limited access to localized learning and agricultural resources-leading to inefficiency and low civic engagement. NagarAI solves this by offering a unified, AI-powered platform that integrates real-time city data, automates complaint handling, provides smart transport insights, delivers agricultural guidance, and includes a structured skill portal, creating a seamless and smarter urban experience.

**Tech Stack:**
- Python
- FastAPI/Flask
- OpenCV
- HTML, CSS, JavaScript
- Gemini API
- React + TypeScript + Vite
- Node.js & Express
- Tailwind CSS + Framer Motion
- Modular architecture handling 7+ modules
