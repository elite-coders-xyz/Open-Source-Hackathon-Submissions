## Project Details

**Project Title:**  
Repostory

**Project Description:**  
Repostory is a CLI tool that scores any public GitHub repository's contributor onboarding readiness from 0 to 100, and tracks whether that score improves over time. It evaluates 7 dimensions — including CONTRIBUTING.md quality, good first issues, PR response time, first-timer retention, issue templates, CI green rate, and setup clarity — filling a gap that tools like OpenSSF Scorecard and GitHub Insights don't address: community health and structural readiness to receive new contributors.

**Tech Stack Used:**  
Python, Click (CLI), SQLite, GitHub REST API, Rich (terminal output), HTML dashboard
