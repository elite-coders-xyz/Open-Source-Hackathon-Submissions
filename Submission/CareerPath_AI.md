## Project Description
CareerPath AI is an intelligent resume assessment platform that parses user documents to provide an
objective ATS score and identify skill gaps. It leverages automated keyword analysis to deliver 
personalized career recommendations and structured learning roadmaps tailored to each user's profile.
By bridging the gap between current experience and industry requirements, the tool empowers job seekers
to optimize their resumes for better recruitment outcomes.

## Tech Stack
Backend Framework: Flask (Python) for routing, file handling, and session management.

Database: SQLite for secure user authentication and login storage.

AI/Analysis Engine: Python with PyPDF2 and python-docx for smart resume text extraction.

Frontend: HTML5, CSS3, and Jinja2 for a clean, dynamic, and responsive user interface.
