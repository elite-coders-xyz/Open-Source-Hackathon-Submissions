## Project Details

**Project Title:**  
RepoSage

**Project Description:**  
*From "I want to contribute" to a real draft PR — in one click.*  

The gap between wanting to contribute to open source and actually merging your first PR is enormous. Beginners often face daunting questions: *Which file do I even edit? How do I fork this correctly? What should I name my branch? What do I write in the PR description?* Most people quietly close the tab. 

**RepoSage** is an intelligent open-source mentorship platform designed to stop this 90% drop-off rate. It handles everything between finding an issue and writing the actual code by serving as a personalized mentor and automation engine.

### 🌱 How it Empowers Beginners:
* **Smart Issue Matching:** Scans your GitHub profile and surfaces `good-first-issues` matched exactly to your tech stack and programming languages. No more endless scrolling.
* **Automated Architecture Diagrams:** Click any issue to get a real-time Mermaid architecture diagram for that repository. Understand the codebase before you even touch a file.
* **Context-Aware AI Chat:** Ask questions without fear (e.g., *"Which file do I need to edit to fix this?"*). DeepSeek and Qwen AI models read the repository and respond with actual, accurate context.
* **The "Start Contribution" Button:** The centerpiece feature. With one click, RepoSage automatically forks the repo, creates a descriptive branch, opens a draft PR with a pre-filled description, and gives you a single command to clone and checkout. Setup that used to take 20 confused minutes now takes under 60 seconds.
* **Interactive Learning Hub & Kanban Tracker:** Track your issues from "Saved" to "Merged" while learning Git, PR etiquette, and codebase navigation through 50+ structured educational modules.

### 🚀 How it Benefits Maintainers:
* **Grow Your Community:** RepoSage significantly lowers the barrier to entry, bringing a steady stream of capable, well-guided contributors to your repository.
* **Extensible AI:** Built on a modular LLM architecture (OpenRouter/Groq), allowing deep-context models to seamlessly analyze and explain massive codebases to new contributors.

**Tech Stack Used:**  
* **Frontend:** Next.js 16 (App Router), React 19, Tailwind CSS v4, shadcn/ui
* **AI:** OpenRouter, Groq (DeepSeek V3 / Qwen 2.5)
* **Data & Core:** NextAuth v5, Octokit (GitHub API)
* **Edge / Infra:** Upstash Redis, Vercel (Edge Runtime)
