## Project Details

**Project Name:**
RepoPulse AI

**Project Description:**
RepoPulse AI is an intelligent codebase assistant and automated Pull Request reviewer designed to supercharge open-source collaboration. Powered by Google's Gemini 1.5 Pro and a custom Retrieval-Augmented Generation (RAG) pipeline, it acts as a tireless co-maintainer by analyzing code diffs, catching potential bugs, and automatically posting constructive review comments on GitHub PRs in real-time. It also features a Doc-Bot for codebase Q&A.

**Tech Stack Used:**
Python, Flask, Google Gemini 1.5 Pro, HTML/Vanilla JS, Tailwind CSS, GitHub Webhooks, PyGithub, RAG Pipeline.
