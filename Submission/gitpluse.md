## Project Details
* **Project Title:** GitPulse // Advanced Developer Analytics Dashboard
* **Project Description:** GitPulse is a modern, metrics-driven developer velocity tracker. The platform aggregates public GitHub REST API streams using asynchronous multi-thread parallel fetching, transforming raw user profiles into a gamified visual ranking dashboard. It includes dynamic impact-score calculations, real-time client-side repository filtering, and automated pipeline fallback schemas to preserve visual state representation during API rate-limiting events.
* **Tech Stack Used:** React.js, Vite, Chart.js, React-Chartjs-2, Custom Dark Theme CSS, Dotenv (`.env`) Environment Variables.
