## Project Details

**Project Title:**  
NetSentinel | Open-Source Real-Time Network Threat Visualizer
**Project Description:**  
NetSentinel is an open-source, real-time network threat visualizer designed to tackle the invisibility of network intrusions (like port scans and brute-force attempts). While enterprise-grade security platforms exist, they are often closed-source and expensive. NetSentinel solves this by streaming live network activity to an interactive 3D dashboard where devices appear as nodes and connections as lines. When a threat is detected via our rule-based pattern matching backend, nodes instantly change color and emit pulsing shockwave animations, translating complex text logs into an intuitive, glanceable security operations console

**Tech Stack Used:**  
Python, FastAPI, WebSockets, React, Vite, Three.js (React Three Fiber), Docker, Render, Vercel
