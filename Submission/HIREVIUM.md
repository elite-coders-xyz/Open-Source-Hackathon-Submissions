## Project Details

**Project Title:**  
HIREVIUM — AI Hiring Intelligence Operating System.

**Project Description:**  
HIREVIUM redefines hiring intelligence by transforming technical vetting into a multi-dimensional, adaptive experience. It operates as a dual-sided workspace:

- For Candidates: An interactive live interview simulator with an Adaptive Difficulty Controller that escalates or de-escalates questions in real time. It evaluates not just syntax, but communication patterns, response latency, and pressure resilience, followed by an AI Career Coach that builds custom learning roadmaps.
- For Recruiters: A unified Hiring War Room workspace containing candidate rankings, skill verification confidence levels, and automated hiring verdicts generated by a simulated committee of tech executives.

Traditional technical screening is broken, leading to wasted engineering sprint hours and candidates struggling through rigid questionnaires. HIREVIUM is a state-of-the-art AI Hiring Intelligence Operating System designed to automate early screening, eliminate resume padding deception through adaptive Q&A, and provide recruiters with multi-persona engineering intelligence.

Key Features and Vetting Pillars :-
1. Adaptive Technical Interview Vetting: Difficulty shifts dynamically based on candidate performance.
 - Strong Answers (Score >= 85): Escalate to architectural questions.
 - Average Answers (60 <= Score < 85): Pivot sideways to cover parallel concepts.
 - Weak Answers (Score < 60): De-escalate to find the competency floor.
2. Early Termination Guard: Halts interviews gracefully after consecutive failures, saving candidate and interviewer time.
3. AI Hiring War Room Committee: A simulated panel of four technical personas (Tech Lead, EM, Lead Recruiter, VP Engineering) evaluates transcripts.
4. Digital Twin Analytics: Visualizes candidate success predictions, talent benchmarks, and learning velocity.

**Tech Stack Used:**  
- Frontend: React 19, Next.js 16 (App Router), TypeScript, Tailwind CSS v4, Framer Motion
- Backend: Python 3.13, FastAPI (Asynchronous endpoints, CORS, routers)
- Database: SQLAlchemy 2.0, SQLite (utilizing aiosqlite for async compatibility)
- AI Integration: Gemini 2.5 Flash Lite via Google GenAI SDK (direct API usage with structured JSON responses)
- Authentication: Salted hashing (Bcrypt compatible with Python 3.13) and JSON Web Tokens (PyJWT)
