## Project Details

**Project Title:**
LeadFlow CRM

**Project Description:**
LeadFlow CRM is a full-stack Customer Relationship Management (CRM) application designed to help businesses manage and organize leads efficiently. The platform allows users to create, view, update, and delete leads through a modern and responsive dashboard.

The project was built during the hackathon to practice real-world full-stack development concepts including CRUD operations, REST APIs, database integration, responsive UI design, and deployment workflows. It provides lead status tracking, dashboard analytics, and a clean user experience for managing customer interactions.
