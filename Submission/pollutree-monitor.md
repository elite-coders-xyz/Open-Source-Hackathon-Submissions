## Project Details

**Project Title:**  
Pollutree Monitor

**Project Description:**  
Pollutree Monitor is a real-time air quality monitoring platform that tracks AQI (Air Quality Index) data from sensors, visualizes pollution trends on interactive maps, and provides AI-powered health advisories and chatbot Q&A using Google Gemini. It helps citizens and administrators make data-driven decisions to combat air pollution and protect public health.

**Tech Stack Used:**  
Next.js 14, React 18, Tailwind CSS, shadcn/ui, Next.js App Router API Routes, Supabase (PostgreSQL), Google Gemini 2.5 Flash, Clerk (role-based auth), Leaflet.js + React Leaflet, Recharts, Vercel
