## Project Details

**Project Title:** VoiceCare: AI-Powered Multilingual Medical Intake & Reception Agent

**Project Description:** VoiceCare is a voice-first medical reception kiosk and clinician dashboard that streamlines patient onboarding in healthcare clinics and hospitals. Patients speak their chief complaints, medical history, and demographics in English, Hindi, or Kannada, and the system generates structured clinical reports for doctors in real-time. All AI processing runs locally using LLaMA 3 via Ollama — ensuring 100% patient data privacy with no PHI sent to external clouds.

**Tech Stack Used:** React 19, Vite, Tailwind CSS v4, Lucide React, React Router DOM v7, Web Speech API, FastAPI, WebSockets, SQLAlchemy, SQLite, PostgreSQL, Ollama, LLaMA 3 (8B)
