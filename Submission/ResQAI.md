## Project Details

**Project Title:**  
ResQAI

**Project Description:**  
ResQAI is an AI-powered disaster reporting and emergency response platform that enables citizens to report disasters such as floods, fires, earthquakes, landslides, and cyclones. The platform provides multilingual support, interactive disaster mapping, SOS alerts, AI chatbot assistance, and analytics dashboards to improve disaster awareness and response.

**Tech Stack Used:**  
- Frontend: React.js, Vite, Tailwind CSS
- Backend: Node.js, Express.js
- Database: MongoDB Atlas
- Maps: OpenStreetMap
- Deployment: Vercel, Render
- AI: Gemini API
