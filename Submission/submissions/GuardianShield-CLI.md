### Short Description
An enterprise-grade, zero-dependency static analysis security utility built for DevOps pipelines and local development workflows. It recursively audits codebases for exposed cloud secrets (AWS, Google, GitHub tokens) and high-risk security anti-patterns (eval, raw SQL injections, disabled SSL) while mathematically generating a repository safety score.
