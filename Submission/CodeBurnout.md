## Project Details

**Project Title:**  
CodeBurnout — Developer Burnout Risk Predictor

**Project Description:**  
CodeBurnout is an AI-powered productivity and health analytics tool that analyzes a developer's GitHub commit history to detect early signs of burnout. It tracks coding patterns such as late-night commits, weekend activity, sentiment of commit messages, and streak behavior to generate a burnout risk score (Low / Medium / High). The tool helps developers understand their work-life balance and avoid overworking before burnout occurs.

**Tech Stack Used:**  
Python 3.10+, Streamlit, GitHub REST API (PyGithub), Scikit-learn (Isolation Forest), VADER NLP, Plotly, GitHub Actions, Streamlit Cloud
