## Project Details

**Project Title:**  
GitPhone

**Project Description:**  
GitPhone is a developer tool that bridges the gap between mobile convenience and professional version control. It allows developers to stage code changes in VS Code and commit them to GitHub from anywhere using a Telegram bot. This solves the problem of developers being unable to commit small fixes or maintain their contribution streaks when away from their laptops. It features real-time sync, dynamic branching, and automatic Pull Request generation.

**Tech Stack Used:**  
FastAPI (Python), python-telegram-bot, Supabase (PostgreSQL), PyGithub, TypeScript, VS Code Extension API, Google's diff-match-patch.
