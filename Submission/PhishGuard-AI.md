## Project Details

**Project Title:**  
PhishGuard AI

**Project Description:**  
PhishGuard AI is an advanced, multi-layered phishing detection platform designed to protect users from malicious URLs. It acts as a one-click security orchestrator that extracts features from any input URL and analyzes them through 9 comprehensive security layers. The system cross-references real-time DNS records, conducts custom raw-socket WHOIS domain intelligence, performs SSL certificate validation, scans live threat intelligence feeds (URLScan.io, ThreatFox, AlienVault OTX), and checks open source blacklists (OpenPhish, PhishTank). Finally, a locally trained Machine Learning model (Random Forest Classifier with 200 estimators) processes a 10-dimensional feature pipeline to output a precise phishing probability score. All findings are aggregated into a unified 0–100 risk scoring index presented inside a responsive, modern dark-themed glassmorphism dashboard, backed by an SQLite persistent history layer.

**Tech Stack Used:**  
React 18, Vite 5, JavaScript, Python 3.10+, FastAPI, Uvicorn, Scikit-learn (Random Forest), NumPy, Joblib, Dnspython, SQLite, CSS (Glassmorphism, Custom Properties).
