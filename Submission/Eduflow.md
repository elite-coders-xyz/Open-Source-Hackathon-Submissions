## Project Details

**Project Title:**
EduFlow — Student Productivity Platform

**Project Description:**
EduFlow is a full-stack web application built for students to manage their academic life in one place. Students can upload and organize notes (PDFs and images), share study resources with their community, track tasks using a kanban-style board with priorities and due dates, and monitor their overall progress from a personal dashboard. The platform supports dark mode, JWT-based authentication, and cloud file storage via Cloudinary.

**Tech Stack Used:**
React, Vite, Tailwind CSS v4, Node.js, Express, MongoDB, Mongoose, JWT, Cloudinary, Multer, React Router, Axios, date-fns, Lucide React, Vercel (frontend), Vercel (backend)
