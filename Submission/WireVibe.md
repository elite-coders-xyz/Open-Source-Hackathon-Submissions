## Project Details

**Project Title:**  
WireVibe — AI-Powered Wireframe to Code Generator

**Project Description:**  
WireVibe is an innovative web application that bridges the gap between imagination and execution. It allows developers and designers to sketch rough wireframes directly on an interactive canvas, and with a single click, transforms them into production-ready HTML/CSS code using Google Gemini 1.5 Flash Vision API. The app solves the problem of spending hours writing boilerplate frontend code — users simply draw their UI idea, click "Vibe It", and get clean, responsive code instantly. It features a full drawing canvas with brush tools, eraser, color picker, image upload, real-time live preview with device toggles (Mobile/Tablet/Desktop), a floating AI assistant (VibeBot), one-click HTML export, and a secure BYOK (Bring Your Own Key) API model that ensures zero server-side key exposure. Built entirely with zero dependencies using Vanilla HTML, CSS, and JavaScript for lightning-fast performance.

**Tech Stack Used:**  
HTML5, CSS3 (Variables, Flexbox, 3D Transforms, Glassmorphism), Vanilla JavaScript (ES6+), Google Gemini 1.5 Flash Vision API, HTML5 Canvas API, Highlight.js
