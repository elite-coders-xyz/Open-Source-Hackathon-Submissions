## Project Details

**Project Title:**  
Aura Finance

**Project Description:**  
Aura Finance is an enterprise-grade quantitative wealth management platform. It integrates a 5-model Machine Learning Ensemble, FinBERT Natural Language Processing, and a Real-Time News Sentinel to deliver high-fidelity market forecasts, live sentiment scores, and portfolio optimization matching Modern Portfolio Theory (MPT).

### Key Features:
- **📈 Real-Time Indian Equities Scroller:** Features the top 10 Indian Equities in an infinite marquee tape with interactive charts and key valuation statistics.
- **📊 MPT Portfolio Optimizer:** Simulates over 5,000 randomized portfolios via Monte Carlo to determine the Maximum Sharpe Ratio weightings with a Cash Allocation Simulator.
- **🔎 Multi-Factor Market Screener:** Interactive dashboard showing Nifty 50 stocks with model accuracy, sentiment scores, and disaster risk ratings.
- **🌐 Global Macro Tracker:** Monitors international benchmarks (S&P 500, Nasdaq, USD/INR, Bitcoin) and tracks institutional flows (FII).
- **💬 Consultative Aura AI Broker:** Professional chatbot powered by Gemini 2.5 Flash, optimized for low latency by fetching PostgreSQL data directly.
- **🧠 Hybrid Ensemble ML Engine:** Combines Amazon Chronos-T5, PyTorch Transformer, XGBoost, LightGBM, and PyTorch LSTM (35% / 20% / 20% / 15% / 10% weights).
- **📰 24/7 News Sentinel Agent:** Automatic news scraping, ProsusAI FinBERT sentiment scoring (-1.0 to +1.0), and 23-category disaster risk scanning.

**Tech Stack Used:**  
React 19, TypeScript, Vite 8, Python 3.11, Flask, PostgreSQL (via Supabase), Gemini 2.5 Flash
