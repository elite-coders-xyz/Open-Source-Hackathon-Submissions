## Project Details

**Project Title:**  
CropGuard AI

**Project Description:**  
AI-powered crop disease detection using ResNet18 deep learning 
model trained on PlantVillage dataset. Uses RAG (Retrieval 
Augmented Generation) with LangChain + FAISS vector store to 
provide treatment advice for detected diseases. Built with 
Streamlit UI.
**Tech Stack Used:**  
Deep Learning:	PyTorch, ResNet18
Dataset:	PlantVillage (Kaggle)
RAG:	LangChain, FAISS
Embeddings:	HuggingFace Sentence Transformers
Frontend:	Streamlit
Language: Python 3.10+
