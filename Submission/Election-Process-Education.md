## Project Details

**Project Title:**  
AI-Powered Election Education Assistant 🗳️🤖

**Project Description:**  
-An interactive AI-powered civic education platform designed to help first-time voters understand the democratic election process in a simple and engaging way.  

-The system uses a structured election timeline (Registration → Nomination → Campaign → Voting → Results), an interactive voting simulator, quizzes, misinformation awareness tools, and a Google Gemini AI assistant to provide personalized civic guidance.

-This project solves the problem of low voter awareness and election confusion by making civic education interactive, visual, and AI-driven.


**Tech Stack Used:**  
- React (Vite)  
- TypeScript  
- Tailwind CSS  
- Google Gemini 1.5 Flash API  
- Vitest
