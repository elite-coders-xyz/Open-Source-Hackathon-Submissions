## Project Details
- **Project Title:** Exam Seating Portal
- **Project Description:**
  A full-stack university admin portal for automated exam seating plan generation.
  Supports bulk student and faculty import via Excel, a branch-interleaving algorithm
  that prevents same-branch students from sitting adjacent, complete hall and faculty
  management, PDF generation with master room-wise summary and hall-wise seating grids,
  and a completely separate Supplementary Exam module where admin manually selects halls
  and faculty. Built for Anil Neerukonda Institute of Technology & Sciences.

- **Tech Stack Used:** Python 3, Flask, SQLAlchemy, SQLite, Bootstrap 5.3, Bootstrap Icons, DataTables, Flatpickr, Chart.js, ReportLab, pandas, openpyxl
