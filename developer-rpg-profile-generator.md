## Project Details

**Project Title:**  
Developer RPG profile generator

**Project Description:**  
Developer RPG Profile Generator is an interactive web application that transforms your live GitHub activity into a gamified, RPG-style character dashboard. It automatically analyzes your commits, PRs, and repositories to generate dynamic "combat stats," skill trees, and quest logs, which you can then export as a themed README.md for your actual Github.
