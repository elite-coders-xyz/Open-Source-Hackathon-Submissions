## Project Details

**Project Title:**  
OpenSource Mentor AI

**Project Description:**  
OpenSource Mentor AI is a full-stack web application that analyzes GitHub profiles and provides personalized recommendations to help developers improve their open-source journey. It evaluates repositories, stars, forks, programming languages, and profile completeness to generate useful insights and an Open Source Mentor Score.

**Tech Stack Used:**  
React
Vite
Node.js
Express.js
GitHub REST API
