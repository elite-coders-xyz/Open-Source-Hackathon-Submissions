## Project Details
- **Title:** NGO Transparency System
- **Description:** A full-stack web app that brings real transparency to NGO donations. Donors track exactly where every rupee goes, NGOs post verified fund usage updates, and admins monitor platform integrity. Features AI credibility scoring for every NGO.
- **Tech Stack:** React.js, Vite, Tailwind CSS, React Router DOM, Vercel
- **GitHub Repository:** https://github.com/Safiya007/ngo-transparency
- **Live Demo:** https://ngotransparency.vercel.app

## Features
- Donor dashboard with donation tracking and impact verification
- NGO dashboard with fund usage updates and AI credibility score
- Admin dashboard with NGO verification and flagging system
- Role-based login (Donor / NGO / Admin)
- Public transparency page per NGO
