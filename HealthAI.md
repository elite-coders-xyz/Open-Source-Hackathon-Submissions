## Project Details

**Project Title:**  
HealthAI Assistant – Intelligent Multilingual Healthcare Support Platform

**Project Description:**  
HealthAI Assistant is a comprehensive AI-powered healthcare platform designed to bridge the gap between patients and healthcare services. The system provides intelligent health guidance, doctor recommendations, appointment booking, emergency assistance, and multilingual communication through a secure and user-friendly web application.
The platform integrates Artificial Intelligence, geolocation services, and secure cloud infrastructure to deliver accessible healthcare support to users from different linguistic and geographical backgrounds. Users can interact with an AI health assistant, locate nearby hospitals, book appointments, receive emergency support, and manage their healthcare activities from a single dashboard.
Built using React, Node.js, Express.js, and Firebase, the platform emphasizes security, scalability, accessibility, and real-world healthcare impact.

**Tech Stack Used:**  

Backend

Runtime: Node.js
Framework: Express.js
Database: Firebase Realtime Database
Authentication: Firebase Admin SDK
Security: Helmet.js, express-rate-limit
File Upload: Multer
Key Dependencies: axios, uuid

Frontend

Library: React 18.2.0
Routing: React Router v6
Authentication: Firebase SDK
Maps: Leaflet + React-Leaflet
UI: Custom CSS with responsive design
Security: React Google reCAPTCHA
